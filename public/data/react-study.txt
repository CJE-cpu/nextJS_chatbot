퀴즈 힌트 예시: <Header />와 <header>의 차이를 생각하세요.

[05. Props]
==================================================
대표 명칭: Props
관련 표현: props, 프롭스, 속성, 부모 자식, 데이터 전달, 매개변수
기능 설명: Props는 부모 컴포넌트가 자식 컴포넌트에 전달하는 읽기 전용 데이터입니다. 자식은 받은 props를 직접 변경하지 않습니다.
기본 사용법: const Greeting = ({ name }: { name: string }) => <p>{name}</p>; // <Greeting name="민수" />
Q. 부모가 자식 컴포넌트에 이름을 전달하려면?
완성형 답변: Props를 사용합니다. 부모는 <Greeting name="민수" />처럼 전달하고 자식은 name을 읽어 표시합니다.
퀴즈 힌트 예시: 함수의 매개변수와 비슷한 역할을 떠올려 보세요.

[06. useState]
==================================================
대표 명칭: useState
관련 표현: useState, 유즈스테이트, state, 상태, 상태 관리, setState, setCount, 카운터
기능 설명: useState는 컴포넌트에 상태를 추가하는 Hook입니다. 현재 상태값과 상태 변경 함수를 반환합니다. 상태 변경 함수를 호출하면 React가 다시 렌더링할 수 있습니다.
기본 사용법: const [count, setCount] = useState(0); // setCount(count + 1)
Q. count를 1 증가시키려면 어떤 함수를 호출하나요?
완성형 답변: setCount(count + 1)을 호출합니다. 이전 상태를 기준으로 안전하게 갱신할 때는 setCount(prev => prev + 1)을 사용합니다.
퀴즈 힌트 예시: 배열 구조 분해 할당의 두 번째 값을 생각하세요.

완성형 답변: onClick에 함수 자체를 전달합니다. onClick={handleClick}처럼 작성합니다.
퀴즈 힌트 예시: onClick 뒤에 함수를 호출하는 괄호를 붙여야 할지 생각해 보세요.

기능 설명: 조건부 렌더링은 상태나 조건에 따라 다른 JSX를 보여주는 방식입니다. 삼항 연산자나 && 연산자를 사용할 수 있습니다.

퀴즈 힌트 예시: map으로 만든 요소에 고유 식별자를 지정해 보세요.

[11. useEffect]
==================================================
대표 명칭: useEffect
관련 표현: useEffect, 유즈이펙트, 이펙트, 부수 효과, effect, 의존성 배열, 동기화
기능 설명: useEffect는 React 외부 시스템과 동기화하는 작업에 사용합니다. 의존성 배열로 재실행 조건을 정하며 정리 함수를 반환할 수 있습니다. 개발 모드 Strict Mode에서는 추가 실행이 있을 수 있습니다.
기본 사용법: useEffect(() => { document.title = title; }, [title]);
Q. title이 변경될 때 문서 제목을 갱신하려면?
완성형 답변: useEffect에서 document.title을 설정하고 의존성 배열에 title을 넣습니다.
퀴즈 힌트 예시: 외부 시스템과의 동기화와 의존성 배열을 생각하세요.

[12. useEffect 정리 함수]
==================================================
대표 명칭: useEffect 정리 함수
관련 표현: cleanup, 클린업, 정리 함수, 구독 해제, clearInterval, removeEventListener
기능 설명: Effect에서 이벤트 리스너나 타이머를 등록했다면 정리 함수에서 해제해야 합니다. 정리 함수는 의존성이 바뀌어 Effect가 다시 실행되기 전이나 언마운트 시 호출됩니다.
기본 사용법: useEffect(() => { const id = setInterval(tick, 1000); return () => clearInterval(id); }, []);
Q. useEffect에서 만든 타이머를 해제하는 방법은?
완성형 답변: Effect에서 return하는 정리 함수에서 clearInterval(id)를 호출합니다.
퀴즈 힌트 예시: useEffect가 반환할 수 있는 함수를 떠올려 보세요.

[13. useRef]
==================================================
대표 명칭: useRef
관련 표현: useRef, 유즈레프, ref, DOM 접근, 포커스, 참조, current
기능 설명: useRef는 렌더링 사이에 유지되는 변경 가능한 참조를 저장합니다. ref.current를 변경해도 그 자체로 재렌더링되지 않습니다. DOM 요소에 접근할 때도 사용합니다.
기본 사용법: const inputRef = useRef<HTMLInputElement>(null); // inputRef.current?.focus()
Q. 버튼 클릭 시 input에 포커스를 주려면?
완성형 답변: input에 ref를 연결하고 inputRef.current?.focus()를 호출합니다.
퀴즈 힌트 예시: DOM 요소를 가리키는 current 속성을 생각하세요.

==================================================
대표 명칭: useContext
관련 표현: useContext, 유즈컨텍스트, context, 전역 데이터, 테마, prop drilling
기능 설명: Context는 여러 컴포넌트가 공통 데이터를 전달받을 수 있도록 돕습니다. useContext로 가장 가까운 Provider의 값을 읽습니다.

완성형 답변: Context Provider로 값을 제공하고 필요한 컴포넌트에서 useContext를 사용합니다.
퀴즈 힌트 예시: 중간 컴포넌트마다 props를 전달하지 않는 방법을 생각하세요.

[15. useMemo]
==================================================
대표 명칭: useMemo
관련 표현: useMemo, 유즈메모, 메모이제이션, 계산 캐시, 최적화, 비싼 계산
기능 설명: useMemo는 의존성이 바뀌지 않는 동안 계산 결과를 재사용하는 최적화 Hook입니다. 모든 계산에 무조건 사용할 필요는 없습니다.
기본 사용법: const filtered = useMemo(() => items.filter(item => item.active), [items]);
Q. 큰 배열의 필터 계산 결과를 재사용하려면?
완성형 답변: useMemo를 사용해 계산 결과를 캐시할 수 있습니다. 실제 성능 문제를 확인한 뒤 적용하는 것이 좋습니다.
퀴즈 힌트 예시: 계산 결과를 기억하는 Hook을 떠올려 보세요.

[16. useCallback]
==================================================
대표 명칭: useCallback
관련 표현: useCallback, 유즈콜백, 함수 캐시, 함수 참조, 최적화, React.memo
기능 설명: useCallback은 의존성이 바뀌지 않는 동안 함수 참조를 재사용합니다. 메모화된 자식 컴포넌트에 함수를 전달할 때 유용할 수 있습니다.
기본 사용법: const handleClick = useCallback(() => setCount(c => c + 1), []);
Q. 함수 참조를 재사용하는 Hook은?
완성형 답변: useCallback입니다. 함수를 실행한 결과가 아니라 함수 자체를 기억합니다.
퀴즈 힌트 예시: useMemo는 결과, useCallback은 함수라는 차이를 생각하세요.
